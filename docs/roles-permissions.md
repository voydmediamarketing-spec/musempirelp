# Role And Permission Matrix

## Roles

- `artist`: full collaboration and project participation
- `provider`: full collaboration and project participation
- `fan`: discovery, follows, reactions, and gated access requests only

## Permissions

| Capability | Artist | Provider | Fan |
| --- | --- | --- | --- |
| Complete onboarding | Yes | Yes | Yes |
| Appear on world map | Yes | Yes | Optional |
| Set city-level visibility | Yes | Yes | Yes |
| Opt into precise location | Yes | Yes | Yes |
| Publish status updates | Yes | Yes | No |
| Upload snippets or media | Yes | Yes | No |
| Follow accounts | Yes | Yes | Yes |
| React to visible activity | Yes | Yes | Yes |
| Send collaboration requests | Yes | Yes | No |
| Receive collaboration requests | Yes | Yes | No |
| Participate in direct chat | Yes | Yes | No |
| Create project rooms | Yes | Yes | No |
| Join project rooms | Yes | Yes | Request only |
| Use AiM beta | Yes | Yes | Limited future scope |
| Access invest placeholder | Read only | Read only | Read only |

## Default Safety Constraints

- Fans do not receive collaborator permissions by default.
- Exact map location is opt-in only.
- AiM remains draft-only for risky actions.
