# Route Map

## Public Routes

- `/`: landing page
- `/login`: authentication entry
- `/auth/callback`: OAuth or email callback
- `/api/openapi`: generated contract artifact

## Authenticated Product

- `/app`: workspace overview
- `/app/onboarding`: first-run onboarding
- `/app/map`: world map discovery and activity
- `/app/collabs`: collaboration requests and direct coordination
- `/app/projects`: project room index
- `/app/aim`: AiM beta
- `/app/invest`: regulated-feature placeholder
