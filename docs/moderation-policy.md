# Moderation Baseline

## Minimum Controls

- Users can report profiles, posts, messages, and project rooms.
- Users can block other users.
- Moderation cases are created for admin review.
- High-risk capabilities remain draft-only in AiM.

## First-Phase Safety Goals

- Protect users from harassment and spam in map discovery and chat.
- Protect location privacy with city-level defaults.
- Prevent fans from receiving elevated collaboration permissions by accident.
- Maintain review records for moderation actions and risky AI-generated outputs.
